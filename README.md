# e-plantShopping

e-plantShopping is a React e-commerce application for browsing and purchasing indoor plants.

This project is part of the IBM Front-End Developer Capstone. It includes product listing, shopping cart functionality using Redux, and a responsive UI.

Features:
- Browse plants by category
- Add to cart / Remove from cart
- Cart total calculation

Built with React, Redux Toolkit, and Vite.
